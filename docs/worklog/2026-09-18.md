## Android 디버그 APK 빌드 수정 (systematic-debugging)
`fvm flutter build apk --debug`가 **4중 순차 원인**으로 실패 → 하나씩 근본 원인 규명·수정. (커밋 `1aa08dd`,
상세 `docs/troubleshooting/2026-09-18-android-debug-apk-build.md`)
1. `permission_handler ^13`이 android **14.1.0**(AGP9/Kotlin2.3/Java17)을 끌어와 툴체인을 앞섬 →
   `permission_handler ^11.3.1` 핀 고정(→ android 12.1.0, 구 DSL 호환). 배경 위치·알림 권한 지원 유지.
2. flutter_local_notifications 19.x의 `java.time` 사용 → core library desugaring 활성화 + `desugar_jdk_libs:2.1.4`.
3. native_geofence minSdk 23 요구 → `minSdk = maxOf(23, flutter.minSdkVersion)`.
4. native_geofence의 kotlinx.serialization 컴파일러 플러그인이 Kotlin 1.8.22엔 미배포 → KGP `1.8.22 → 2.1.0`.
- 틀렸던 시도: Kotlin만 2.1.0으로 먼저 올렸으나 permission_handler 14는 AGP9/Kotlin2.3 요구라 무효 → 되돌리고
  permission_handler를 아래로 정렬하는 방향으로 수정(문서에 기록).
- 결과: **APK 빌드 성공**(`app-debug.apk`), `fvm flutter analyze` 무경고, 테스트 34/34 유지.
  최종 툴체인: Flutter 3.29.2 / Gradle 8.10.2 / AGP 8.7.0 / Kotlin 2.1.0.
