# 브레인스토밍 — 권한 온보딩 (2026-09-21)

핵심 루프의 두 번째 페이지 슬라이스. 스펙: `docs/superpowers/specs/2026-09-21-permission-onboarding-design.md`,
청사진: `docs/design/2026-09-21-permission-onboarding.html`.

## 다룬 주제

지오펜싱 알림에 필요한 위치("항상 허용")·알림 권한을 안내/요청하는 온보딩 화면의
노출 시점·건너뛰기 정책·화면 구조·범위·기술 결정.

## 결정 (확정)

| 질문 | 결정 | 근거 |
| --- | --- | --- |
| 노출 시점/반복 | **첫 실행에만 게이트** | `onboardingCompleted` 플래그로 이후 홈 직행. 매 실행 노출은 성가심 |
| 건너뛰기 정책 | **언제든 건너뛰기 허용(논블로킹)** | 스펙의 "순수 목록 앱으로 계속 사용" 방침과 일치 |
| 화면 구조 | **단일 화면, 순차 권한 카드** | Android 백그라운드 위치 2단계 제약을 한 화면에서 순서로 표현. 위저드는 MVP에 과함 |
| 홈 배너 | **이번 사이클 포함(기본 배너)** | 건너뛰기/거부 사용자 재유도 경로를 완결 |
| 권한 서비스 위치 | **`core/permissions/`** | onboarding·home이 공유하는 크로스커팅 서비스 |
| 완료 플래그 저장 | **Drift `app_settings` KV 테이블** | shared_preferences 신규 의존성 회피, in-memory 테스트 |

## 핵심 제약 (설계에 반영)

- Android 10+: 백그라운드 위치("항상 허용")는 foreground("앱 사용 중") 허용 후 **별도 요청**.
- Android 11+: "항상 허용" 요청은 다이얼로그가 아니라 **시스템 설정으로 딥링크** → 버튼 "설정에서 허용".
- Android 13+: 알림(POST_NOTIFICATIONS) 별도 권한. 그 이하 `notApplicable`.
- Google Play prominent disclosure: "항상 허용" 요청 직전 백그라운드 위치 고지 필요.

## 검토한 대안 (미채택)

- **위저드(화면당 권한 1개)** — 화면 전환 과다, MVP 과함.
- **단일 화면 일괄 요청(버튼 하나)** — 백그라운드 딥링크·거부 흐름이 불투명.
- **매 실행 권한 재확인 화면** — 스펙 철학과 맞으나 사용자 피로.
- **shared_preferences로 플래그 저장** — 의존성 추가 회피 위해 Drift KV 선택.

## 미해결 / 후속 (비범위)

- 실제 지오펜스 등록·알림 발생 (다음 페이지).
- 매장 시드 적재 (다음 페이지).
- GPS(위치 서비스) 꺼짐 감지·유도.
- 앱 lifecycle(resume) 시 권한 상태 자동 재확인 (이번엔 build 시 조회).
- iOS 권한 흐름.
