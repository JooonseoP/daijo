홈 — 빈 상태

인트로(스플래시) 페이지

  • 노출 — 매 실행 시 표시, 약 1.5~2초 후 홈으로 자동 전환.
  • 구성 — 앱/회사 로고(현재 자리표시자), 앱 이름 다이저, 슬로건, 하단 회사 표기.
  • 위치 고지 — 백그라운드 위치 사용 목적을 문구로 고지만 한다(구글 플레이 사전 고지 충족). 실제 권한 요청·지오펜싱은 다음 페이지.

홈(쇼핑 목록) 페이지

  • 추가 — 상단 인라인 입력줄에 이름 → 엔터/＋. 추가 후 입력줄 비워 연속 입력.
  • 수정 — 항목 이름 탭 → 인라인 편집.
  • 수량 — 각 행 스테퍼(－/＋), 기본 1. 1에서 －는 비활성.
  • 완료 — 체크박스 탭 → 회색·취소선 후 "완료" 구분선 아래로 이동. 해제하면 위로.
  • 삭제 — 왼쪽 스와이프(즉시 삭제, v1은 Undo 없음 — 후보로 기록).
  • 정렬 — 미완료(등록순) → 완료(등록순).
  • 버전 표시 — 화면 하단에 앱 버전(예: v1.0.0)을 작게 표시.
